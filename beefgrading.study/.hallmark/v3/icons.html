Fleece grader app icon

Four candidates for the home-screen icon. Each is shown in a rounded app mask at 180px and 48px on bone, white and ink, plus one copy with the maskable safe zone (central 80% circle, dashed) over the square art.

All art is inside the circle. Each icon is a standalone 512 unit SVG with its own background, so it can be lifted out as a file. Fills are token values written as OKLCH.
